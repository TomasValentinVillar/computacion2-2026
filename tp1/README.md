"Usé privileged porque un monitor de procesos tipo htop necesita leer /proc de todos los procesos del sistema, incluidos los symlinks de /proc/<pid>/fd/ de procesos ajenos. Eso requiere saltear varias capas de aislamiento simultáneas (capabilities + seccomp + LSM/AppArmor), y la forma limpia de hacerlo es privileged. Trade-off: se resigna el aislamiento del contenedor, aceptable para una herramienta que por naturaleza necesita visibilidad total del sistema."
